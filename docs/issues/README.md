# Issues

One file per problem in this project that nobody is fixing right now.

- Copy `TEMPLATE.md` into `open/` and name the file after the problem in kebab case, for example `thumbnail-gallery-misses-renamed-presets.md`. Do not number files.
- Fill in every heading. Write "Unknown" where the answer is not known yet.
- Fixing the problem means moving the file to `closed/` under the same name and filling in its resolution in the same commit as the fix.
- A problem you are fixing in the next few minutes does not need a file.
- Problems in a preset or in someone else's software belong here only when they change how this code has to be written. `../remaining-presets.md` is the scan of presets that fail or render badly.
